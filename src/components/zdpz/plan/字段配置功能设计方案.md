# 功能设计方案

## 一、功能概述

> 简要描述功能的背景、目的和核心价值

**所属模块**：资产信息卡变动批量编辑 - 字段配置
**开发人员**：（待填写）
**预计工时**：（待填写）

**功能背景**：

资产信息卡是用于记录资产（用户具有价值的物品）各种属性的信息卡片。

**资产分类**（共用属性类别）：
- 土地、房屋、图书、档案、无形资产、专用设备 等

**字段构成**：
- **共有属性**：资产编号、资产名称、取得方式、取得日期 等（所有资产类别通用）
- **独特属性**：不同资产类别特有的属性

以上统称为"资产卡片的字段信息"。

**功能目的**：

在资产信息卡变动批量编辑场景中，管理员用户通过字段配置功能，实现对各字段的精细化管控：
1. **是否可编辑** - 设置批量操作时哪些字段允许改动
2. **弹出选择方式** - 字段触发方式（输入框、下拉框、弹框选择等）
3. **是否多选** - 配置字段是否支持多选
4. **联动过滤公式** - 字段值的变化受其他字段状态约束

**关键约束**：
- **使用者**：仅限管理员（普通用户不可配置）
- **配置方案**：所有资产类别统一一套配置，管理员可配置多套方案供不同角色（经办岗、审核岗、部门领导等）使用
- **功能定位**：独立的管理功能，非批量编辑功能的入口

## 二、需求理解

### 2.1 用户故事

- 作为 **管理员用户**，我希望配置不同角色使用批量编辑时的字段权限，以便实现精细化的权限管控

### 2.2 功能范围

**包含**：
- 方案管理：新增、删除、切换配置方案
- 资产信息卡树：按资产类别分组展示所有资产信息卡，支持搜索过滤
- 字段配置：对各资产信息卡的字段进行分组、排序、配置
- 字段属性配置：是否可编辑、是否多选、是否只能选叶子节点、过滤值
- 重置功能：重置当前方案所有信息卡配置为默认方案
- 保存功能：保存当前方案所有配置
- 元数据默认方案：系统初始化时为每个业务类型生成默认方案

**不包含**：
- 批量编辑功能本身（仅做字段配置）
- 拖拽字段到中间列
- 公式配置（预留字段）

### 2.3 业务流程

1. **管理员登录** → 进入字段配置管理页面
2. **选择/新建方案** → 选择已有方案或新增方案（填入方案名称、关联角色、业务类型、单位选择）
3. **选择资产信息卡** → 在左侧树中点击某个资产信息卡
4. **配置字段** → 在中间列对字段进行分组、排序
5. **设置字段属性** → 点击某个字段，在右侧设置其配置项
6. **保存方案** → 点击保存按钮
7. **切换方案** → 可切换到其他方案继续配置

**左侧列操作区顺序**（从上到下）：
1. 新增按钮
2. 编辑按钮
3. 保存按钮
4. 删除按钮
5. 重置按钮
6. 方案下拉选择

**左侧列资产信息卡树**：
- 树形结构，根节点为资产分类
- 分类下展示具体资产信息卡
- 支持搜索/过滤
- 点击资产信息卡，中间列展示该卡片字段

**中间列**：
- 按5个分组展示（基本信息、财务信息、使用信息、特殊信息、处置信息）
- 上移/下移按钮：支持同分组内调整顺序，支持跨分组移动

**右侧列**：
- 点击中间列字段后显示配置项
- 配置项：isEdit(是否可编辑)、isMultiple(是否多选)、isleaf(是否只能选叶子节点)、filterVal(过滤值)

### 5.3 跨组件数据流

```
BatchEditConfig (根容器)
```

## 九、边界情况

| 场景 | 处理方式 |
|------|---------|
| 未选择方案时操作 | 禁用保存、删除、重置、编辑按钮 |
| 未选择资产信息卡时 | 中间列显示空，右侧列显示提示文字"请选择资产信息卡" |
| 未选择字段时 | 右侧列显示提示文字"请选择字段" |
| 切换资产信息卡有未保存改动 | 提示用户是否保存当前改动 |
| 切换方案有未保存改动 | 提示用户是否保存当前改动 |
| 删除方案 | 弹出确认对话框，确认后删除 |
| 重置方案 | 恢复为元数据默认方案，覆盖当前修改 |
| 新增方案名称重复 | 提示"方案名称已存在" |
| 网络请求失败 | 显示错误提示，保留当前操作状态 |
| 字段配置为空 | 取字段类型的默认值（isEdit=true, isMultiple=false等） |
| 资产信息卡树 | 默认不展开，用户可手动展开 |
