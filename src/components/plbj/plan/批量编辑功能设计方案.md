# 资产信息卡变动批量编辑功能设计方案

## 一、需求概述
### 1.1 业务背景
资产信息卡是记录资产信息的卡片，资产信息卡变动业务用于修改信息卡的字段内容。批量编辑功能让用户可以：
- 选择若干条信息卡进行批量操作
- 从外部导入信息卡进行批量操作

### 1.2 功能需求
#### 1.2.1 字段配置
- 字段的编辑属性（是否可编辑、编辑方式等）由后端返回
- 字段之间存在联动关系，例如：字段A被勾选后，字段B变为不可编辑
- 修改字段后，后端重新返回最新字段配置

#### 1.2.2 字段校验
- 后端校验当前编辑的所有信息卡字段，返回校验信息
- 前端展示校验信息，将问题字段在表格中标注
- 用户点击校验信息可自动锚点定位到对应的问题字段

#### 1.2.3 导入导出
- 导入：从外部导入Excel文档中的资产信息卡
- 导出：调用后端接口，接口返回什么就导出什么

#### 1.2.4 批量编辑方式
- 行内编辑：单独编辑每个信息卡的字段
- 列操作：批量编辑不同信息卡的同一字段

#### 1.2.5 展示要求
- 资产信息卡字段表格按卡片类型分页签展示
- 每个页签内的数据支持分页

#### 1.2.6 暂存与确定
- 暂存：将当前修改保存到后端
- 确定：最终提交

#### 1.2.7 校验范围
- 校验当前页签下的所有数据（跨分页）
- 锚点定位需支持跳转到表格不同页

#### 1.2.8 搜索
- 搜索范围：当前页签内

#### 1.2.9 是否只显示错误数据
- 点击开关等同于执行一次校验，校验完成后自动过滤显示有问题的数据

#### 1.2.10 批量编辑已选资产
- 选中信息卡后点击此按钮，弹出选择字段弹窗
- 选择或填写这些信息卡的公共字段属性值
- 点确定后相当于一次暂存，更新到表格中

#### 1.2.11 暂存
- 保存当前页签所有修改过的数据

#### 1.2.12 页面布局（全屏弹窗）
- **顶部栏**（从左到右）：信息卡总数、搜索框、是否只显示错误数据开关、导出按钮、导入按钮、批量编辑已选资产按钮、当前页签数据校验按钮
- **中间区域**：分页签展示的信息卡表格（支持分页）
- **底部区域**：当前页签校验信息（默认隐藏，点击校验按钮后显示）
- **弹窗按钮**：暂存、确定、取消
- **切换页签时**：若当前页签有未暂存的修改，需提示用户

## 二、业务分析
### 2.1 资产信息卡字段梳理
#### 2.1.1 字段特点
- 每个卡片类型有独特的字段，同时也有大部分共有的字段
- 字段配置（是否可编辑、编辑控件类型等）由后端动态返回
- 字段之间存在联动关系，修改某字段后后端会重新返回最新字段配置

#### 2.1.2 字段示例（土地类型）
| 字段编码 | 字段名称 | 控件类型 | 字段分组 |
|----------|----------|----------|----------|
| asset_code | 资产编号 | Input | BASE |
| asset_name | 资产名称 | Input | BASE |
| obtain_method | 取得方式 | gms-basedata-treelist | BASE |
| obtain_date | 取得日期 | DatePicker | BASE |
| asset_use_code | 资产用途 | gms-basedata-treelist | BASE |
| original_value | 资产原值 | InputNumber | FINANCE |
| net_value | 资产净值 | InputNumber | FINANCE |
| accum_depre | 累计折旧 | InputNumber | FINANCE |
| use_department | 使用部门 | InputDepartment | USE |
| custodian | 保管人员 | InputPerson | USE |
| use_status | 使用状态 | gms-basedata-treelist | USE |
| land_location | 土地坐落 | Input | SPECIAL |
| land_area | 土地面积 | InputNumber | SPECIAL |

#### 2.1.3 后端字段配置格式
后端返回字段配置结构示例：
```json
{
  "BASE_FILED_LIST": [{
    "asset_use_code": {
      "sort": 1,
      "title": "资产用途",
      "field": "asset_use_code",
      "type": "gms-basedata-treelist",
      "config": {
        "isEdit": true,
        "isMultiple": true,
        "filterVal": "01,02,03"
      }
    }
  }]
}
```

#### 2.1.4 校验规则
- 字段校验规则由后端执行，前端只负责展示校验结果
- 校验一般在保存时由后端执行

### 2.2 业务流程图
1. 用户新建资产变动申请
2. 选择要变动的资产（可多选）
3. 点击「批量编辑」按钮，打开批量编辑弹窗
4. 在弹窗内进行字段编辑（行内编辑或列操作）
5. 可选择导入Excel补充资产信息
6. 编辑完成后点击「确定」，完成批量编辑
7. 后续进入审批流程（与批量编辑无关）

```
新建变动申请 → 选择资产 → 批量编辑 → 确定 → 审批流程
```

## 五、页面设计
### 5.1 页面入口
本功能为全屏弹窗形式，非独立页面。从资产变动申请页面点击「批量编辑」按钮唤起。

### 5.2 页面布局
```
┌─────────────────────────────────────────────────────────────┐
│ BatchEditToolbar                                             │
│ [信息卡总数] [搜索框] [错误过滤] [导出] [导入] [批量编辑] [校验] │
├─────────────────────────────────────────────────────────────┤
│ BatchEditTabs                                                │
│ [页签1] [页签2] [页签3] ...                                  │
├─────────────────────────────────────────────────────────────┤
│                                                              │
│  BatchEditTable (VxeTable)                                   │
│  - 分页展示当前页签数据                                       │
│  - 支持行内编辑、列操作                                       │
│  - 问题字段红色高亮                                           │
│                                                              │
├─────────────────────────────────────────────────────────────┤
│ ValidationPanel（默认隐藏，点击校验后展开）                    │
│ 序号 | 错误信息 | 所在行                                     │
│ 点击行可锚点定位                                              │
├─────────────────────────────────────────────────────────────┤
│                    [暂存]  [确定]  [取消]                     │
└─────────────────────────────────────────────────────────────┘
```

### 5.3 交互流程
1. 打开弹窗 → 加载资产数据和字段配置
2. 切换页签 → 若有未保存修改则提示确认 → 加载目标页签数据
3. 编辑单元格 → 修改字段 → 调用后端接口获取最新字段配置
4. 点击校验 → 显示加载状态 → 展示校验结果 → 高亮问题字段
5. 点击校验信息行 → 定位到问题行（可能是当前页或需要翻页）
6. 点击暂存 → 保存当前页签所有修改
7. 点击确定 → 保存并关闭弹窗
8. 点击取消 → 提示未保存数据 → 关闭弹窗

## 七、实现难点分析
### 7.1 字段联动
- 修改字段后需调用后端接口获取最新字段配置
- 根据最新配置更新字段的编辑状态（是否可编辑等）

### 7.2 跨页校验定位
- 校验范围是当前页签所有数据（跨分页）
- 点击校验结果需定位到对应页码和行

### 7.3 未保存数据提示
- 切换页签、关闭弹窗时检查未保存数据
- 给出明确提示让用户确认操作
