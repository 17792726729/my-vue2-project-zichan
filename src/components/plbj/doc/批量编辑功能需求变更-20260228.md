# 需求介绍

## 变更范围

基于原有“批量修改”功能（参考“资产验收-验收入库-批量修改”功能）进行功能优化，并组件化应用与其他功能模块中。

“批量编辑”功能将会应用于“资产验收”、“信息卡变动”、“信息卡拆分”等模块中，因此，建议将此功能组件化，后续有其他业务需要的话可以快速增加。

### 变更项说明

1.  界面布局、样式，按UI规范及上图调整。
2.  去除“批量编辑全部资产”功能。
3.  去除“错误信息导出”功能。
4.  增加导入导出功能。
5.  增加变动导出模板配置功能。——待讨论
6.  增加“当前页签校验信息”部分【隐藏/展开】功能。

### 交互逻辑说明

1.  **整体页面**
2.  资产信息按照卡片类型，通过页签切换形式分别展示对应资产信息数据，页签内容长度超出区域的部分，可通过点击左/右侧的方向箭头进行滑动。
3.  若当前页签存在已修改但未暂存数据，切换页签时提示：“存在未保存数据，切换页签后将丢失，是否继续”，点击【确定】后切换页签，点击【取消】后取消页签切换操作。
4.  资产信息卡片类型包含数据条数为0的页签，不显示；在页签左上方展示全部信息卡数量，展示格式为：“信息卡总数 144 张”。
5.  页签展示页签名称和该页签包含信息卡数量。
6.  页面内容区域分为上下两部分，分别为“资产信息编辑”和“校验信息展示”，上半部分占70%，下半部分占30%，，两部分的内容超出区域，会有横纵滚动条，下半部分支持拖拽调整高度。
7.  “资产信息编辑”区域，以列表形式展示资产信息，用户可在列表单元格中直接编辑可编辑项，翻页时自动执行暂存操作。列表展示效果如下：

- 无问题行无底色；
- 有问题行浅粉底色；
- 问题单元格浅红底色；
- 行选中时底色浅蓝；
- 固定列到序列号。

1.  “校验信息展示”区域在初始进入“资产信息批量修改”页面时，默认为隐藏状态（如图1所示），可通过点击【展开】按钮或执行校验操作，展开“校验信息展示”区域（展开效果如图2所示）。
2.  **资产信息模糊查询功能**

- 支持资产编号和资产名称模糊查询；
- 执行数据范围是当前标签。

1.  **是否只展示错误数据功能**

- 通过点击“是否只展示错误数据”开关，设置页面只展示校验有问题的资产信息数据；
- 打开开关自动检查当前页签，切换页签自动检查

2.  **批量编辑已选资产功能**

“批量编辑已选资产”功能是对当前页签下多条已选数据的多项信息进行统一修改，修改后，所涉及的资产卡片信息项的值将相同。具体功能逻辑如下：

1.  执行数据范围：当前页签下的已选数据。
2.  批量修改步骤：至少选中一条待修改数据 -> 点击【批量编辑已选资产】按钮，打开操作弹窗 -> 选择本次批量修改的字段（页面如图3所示） -> 点击【下一步】按钮进入批量修改页面，填写修改项内容（页面如图4所示） -> 点击【确定】按钮完成修改。
3.  “选择本次批量修改的字段”页面（图3）只展示可编辑字段。
4.  **导入/导出功能**
5.  执行数据范围：导入/导出操作是所有页签、所有数据整体导入/导出。
6.  导出文件要求：

- 导出excel表格，区分可编辑字段与不可编辑字段，不可编辑字段设置浅灰底色；
- 导出时先执行全部页签数据校验，给予校验有问题的字段红色底色以及校验信息提示，如图8所示：

图8 导出文件校验有问题字段提示示例

1.  导入文件要求：

- 导入文件格式应与导出文件保持一致；
- 不可编辑字段不更新，一系统为准；
- 导入后自动执行运行时赋值公式；
- 导入数据后，无需自动自动执行校验（在最终提交保存时强制校验）。

1.  **当前页签数据校验功能**
2.  执行数据范围：当前页签所对应的资产信息卡片类型全部数据。
3.  点击【当前页签数据校验】按钮后，页面展示loading页，提示：“正在校验，请耐心等待”。
4.  校验错误信息展示：

- 以列表形式展示当前页签资产信息校验错误信息，列表字段包含序号、错误信息、所在行；
- 错误信息列表每一行展示一个单元格的错误信息，属于同一行资产信息的在相邻行展示，并按单元格前后顺序排列，如图9所示：

图9 错误信息展示示例

- 点击错误信息所在列表行，自动锚点定位到问题对应的上半部分（资产信息列表）资产信息所在单元格，若锚点位置需要翻页，则先暂存当前页数据，然后翻页。

1.  **取消、暂存、确定按钮功能**
2.  【取消】按钮：点击页面下方【取消】按钮，提示“退出页面后，未保存数据将丢失，是否确认退出”，确认后关闭“批量修改”页面，“取消”后此页面保持不动。提示框如图10所示：

图10 退出页面提示示例

1.  【暂存】按钮：点击页面下方【暂存】按钮，暂存当前页签修改的所有数据，自动执行运行时赋值公式。
2.  【确定】按钮：点击右下角【确定】按钮，系统自动进行全部数据的校验，完全通过后提交保存；保存成功前，页面展示loading页，提示：“正在保存，请耐心等待”。
